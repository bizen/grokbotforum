Lauren Tan さん（@poteto）が日本時間11月2日、ブラウザゲーム「[tibo.dog](https://tibo.dog/)」を公開しました。Grok Bot と Cursor を使って作ったもので、ドメイン代は5.99ドルだったそうです。X の投稿の中でもそのまま遊べるようにしてあります。

あとから投稿した裏話がかなり具体的です。いくつか拾うと：

- サイドプロジェクトとして作り始めたのは4日前で、その間に約1,150件の PR を入れた
- コードに問題を見つけるたびに、Bot にそれを防ぐ lint ルールを作らせた
- ストーリーやカットシーンなどの状態遷移のバグ探しに TLA+ を多用した。主要なシステムごとに形式検証のスキルがある
- 毎フレーム動くコードは `.hot.ts` という拡張子にして、そこではオブジェクトの生成を lint で禁止。GC によるカクつきを抑えている
- シミュレーションは完全に決定的で、ハイスコアを投稿するとサーバーがその回を丸ごと再生して不正がないか確かめる
- 音声ファイルはなく、音楽も効果音もブラウザ内でゲームボーイ風の音源を使ってその場で合成している。ピクセルアートもすべてコードで描いている
- 中くらいの性能のスマホで、敵500体でも60fpsが目標。最初のダウンロードは gzip で約124KBで、予算を超えるとビルドが失敗する
- 難易度の調整は、Bot にゲームをヘッドレスで遊ばせて生存率を見ながら行った
- コードコメントは lint で禁止。説明が要るなら名前かテストを直す、という方針

「なんでこんなによくできてるの」という @aidenybai さんの反応には、「pstack を使った」と返しています。pstack は Cursor の GitHub で公開されているスキル集で、上の lint や形式検証のような進め方を Bot に覚えさせるためのものです。

日本時間11月3日の投稿では、公開からストーリーモード以外で10万回近く遊ばれたと報告していました。ストーリーより本編のほうが面白いそうで、追加してほしい内容をリプライで募っています。
