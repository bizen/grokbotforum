Grok Bot の公式 changelog が11月18日付で更新され、最新は v1.2.3 になりました（1.2.1 と 1.2.2 を含む）。[前回取り上げた v1.2.0](/news/grok-bot-v1-2-0/) からの主な変更をまとめます。

## 新機能

- コネクタのページで、ツールごとに Always allow、Auto-review、Needs approval、Blocked のどれにするかを選べるようになりました（0.70.2 以降）。
- MCP App の中のメッセージボタンを押すと、その文がチャット欄に入り、そのまま送れる状態になります。
- Grok Bot への登録は18歳以上が条件になりました。
- チーム管理者は、組み込みの GitHub コネクタが使えるツールを絞れます。絞られているときは Bot がそう伝えます（Teams 向け）。

## ルーティンとコネクタまわり

- ルーティンがアカウントの再接続を必要とするとき、再接続カードが通知としても、Slack や Microsoft Teams の DM としても届きます（0.79.2 以降）。
- コネクタのサインインが切れたルーティンは、サインインし直すまで予定の実行を飛ばします。
- ルーティンが、自分が動いているチャットのそれまでの会話を読めるようになりました。
- Bot の手伝い役が使うコネクタがサインアウトしていると、チャットに再接続カードが出ます（0.79.2 以降）。
- コネクタがあるサイトでは、ブラウザを開く前にコネクタを使うか、その接続カードを出します。
- すでに接続したコネクタのツールが見当たらないときは、読み込み直して同じ返信の中で続けます。

## そのほかの改善と修正

- Bot の記憶が、人や組織、あなたのプロフィール、いつもの指示、プロジェクトに分けて保存されるようになりました。
- X を接続していない状態で X の投稿を頼むと、X の接続カードが出ます（1.1.0 以降）。
- フライトの予約では航空会社ごとの手順に従い、最終購入を確認できないときは、もう一度クリックせずにリンクを送ってきます。
- 各ターンの MCP App のカードが残るようになり、後のカードで前のカードが置き換わらなくなりました。
- クレジットを追加すると使用量制限のトレイが消え、プラン変更後も新しいプランが有効になれば警告が消えます。
- スマホから送った写真や PDF が Bot のコンピューターに届き、開けるようになりました。
- 通話の転送中に呼び出し音が鳴っている間、Bot が「転送に失敗した」と言わなくなりました。

このほかにもチーム・Enterprise 向けの管理機能や細かい修正が入っています。全文は changelog で確認できます。
