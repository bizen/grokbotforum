公式の changelog が11月3日から6日まで毎日更新されて、最新は11月6日付の v0.79.3 になりました。このサイトで前に取り上げた v0.78.1（10月27日）からの主な変更をまとめます。

## 11月5日（0.79.0〜0.79.2）

いちばん項目が多いのがこの日です。

- ギフトを探してと頼むと、Bot が贈る相手、予算、用途、いつまでに届けたいかを聞くようになりました。期日に間に合わないものは注文しません。
- 米国の大手航空会社のいくつかのサイトで、Bot がサイトの手順どおりにフライトを予約します。途中で止まったときは、続きを自分で進めるためのリンクが返ってきます。
- Gmail と Outlook の下書きカードに添付ファイルが表示され、Send で添付ごと送られます。
- Web ページに AI エージェント向けの指示が隠されていたら、Bot はそれを見つけたことを伝え、指示には従いません。
- Bot のコンピューターで `ssh` と `psql` が使えるようになりました。
- Library に Pinned、All、Pages、Media、Links、Files、Apps のフィルターが付きました。
- Bot が実在の人物の画像を作ったり編集したりできるようになりました。よく知られた人物は参考写真を使います。
- デスクトップアプリのアイコンが新しいフラットなデザインになりました。
- Tesla の解錠や、誰かに運転させるコマンドは、毎回承認を求めるようになりました。

## 11月6日（v0.79.3）

- 共有した Page のタイトルバーに、ダークテーマとライトテーマを切り替えるボタンが付き、選んだほうが記憶されます。
- 共有している Slack ワークスペースの人が Team Bot に直接メッセージを送れるようになりました（Teams 向け）。
- 電話がつながらなかったとき、表示が「Didn't go through」から「No answer」に変わりました。

## 11月3日・4日

- サブスクリプションの請求について、Bot が返金を依頼できるようになりました。何かを送ったり申し込んだりする前に、依頼できる方法を一覧で見せます。
- 音声入力の内容を、そのまま音声メモとして送れるようになりました。チャットで再生でき、文字起こしも見られます。
- Bot がクラウドエージェントを起動すると、そのやりとりがチャットに会話の形で表示されます。
- フライト、宿、食料品のカートを合計額ごと承認すると、Bot はそのまま支払いまで進めます。大きな変更があったときだけ確認し直します。
- いつもの買い物リストの定期再注文は、1回の注文ごとに承認を求め、その承認画面に合計額が出ます。
- Tailscale プラグインから個人の tailnet をつなげるようになり、Bot がその中の MCP サーバーに届くようになりました。

細かい修正はほかにもたくさんあります。全項目は公式の changelog で確認できます。

Grok Bot チームの matt palmer さん（@mattyp）は、日本時間11月11日未明に「What's new in Grok Bot」という7分半ほどの動画を X に投稿しました。チャプターは電話、共有シート、X カード、買い物のセール、ギフト、Team Bots、検索、隠し指示の警告、下書きの添付、サインアウト、天気、細かい更新のまとめ、使用量についての話、という順番です。上の投稿から見られます。
