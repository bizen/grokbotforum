Greg Isenberg さん（@gregisenberg）が日本時間11月12日、YouTube で「Grok Bot: Engineering, Design, Content, Money, Shopping」という約48分の動画を公開しました。ゲストの Ras Mic さん（@Rasmic）が、仕事と生活を Grok Bot でどう回しているかを見せる内容です。

Greg さんは X で「Grok Bot は今いちばんの AI エージェントのオーケストレーターで、これまで見た中で最高のセットアップ」と紹介しました。その投稿を、イーロン・マスクが同じ日の14時59分に「Try Grok @Bot」と引用しています。

## 動画の中身

動画の説明文によると、Ras Mic さんは自分を「Grok Bot maxi」と呼んでいて、話は5つの分野に分かれています。

- **開発**：本気のプロジェクトには1つずつ Bot を作り、思いつきは汎用の開発用 Bot に投げる。役に立たなくなった Bot は消す。夜にアイデアを送っておくと、朝には GitHub にリポジトリができている。
- **Grok Bot が指揮して Claude Code が書く**：計画の見直しは Grok Bot、コードは Claude Code。数時間走らせて、動く PR が5つ返ってきた例を紹介している。Claude Code と組み合わせる理由としては、夕食中にスマホで PR を見たり、運転中にスピーカーで Bot と話したりできる使い勝手を挙げている。
- **デザイン**：X や Mobbin で集めた参考画像を送り、Paper の MCP を通してデザインシステムを作らせる。お兄さんの服のブランドでは、Paper でデザインしたストアを Shopify のフロントエンドとして作った。
- **コンテンツ**：YouTube 用の Bot が毎日9時と17時に X を調べ、元の投稿、タイトル案、資料つきでネタを3つ送ってくる。
- **お金と買い物**：Plaid でつないだ口座の取引を相談役の Bot が読み、思いつきの出費を止める。買い物用の Bot は eBay を毎日見て、PS5 Pro のときは売り手にメールで問い合わせ、本人の確認を取ってから購入した。

[Grok Bot 1.0](/news/grok-bot-1-0/) で「AI チームメイト」を打ち出したのと同じ日に、個人の使い方の動画をイーロンが勧めた形です。セットアップの細部は動画で確認できます。
