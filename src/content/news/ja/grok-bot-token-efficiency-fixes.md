イーロン・マスクが日本時間11月8日夜、「Grok Bot fixes for improved token efficiency and smarter behavior are underway」と X に投稿しました。Grok Bot のトークンの使い方と動きをよくする修正を、いま進めている、という意味です。

その約16分前、Derek Neighbors さん（@dneighbors）への返信では「I will dig into this today」（今日調べる）と書いています。Derek さんは「先週は200ドルのプランがフル稼働で7日もった。今週は中程度の負荷で14時間しかもたない」と報告していました。この数字は本人の申告で、ほかの人が確かめたわけではありません。

話のきっかけは、@Texas_Twins_Dad さんが日本時間11月8日未明に「Grok Bot の使用量が尽きたらどうする？」と投稿したスレッドです。マスクは同日午後、「使用量を増やすのはワンクリックで簡単ではないのか」と返しています。

同じ日、Tesla Owners Silicon Valley（@teslaownersSV）は「Ultra より上のプランはいつ出るのか。週のリセット前に3日ほどで上限に達する」と尋ねました。マスクは「従量課金（per token pricing）に切り替える簡単な方法はあるのか」と返しています。従量課金のプランが実際に用意されるかどうかは、この投稿だけでは分かりません。

その後、プロフィールに Cursor と Grok Bot（SpaceXSI）と書いているマット・パーマーさん（@mattyp）が、マスクの投稿を引用しました。「トークン効率と動作の改善を進めている。多くの人が @bot の上に大事なワークフローを作っている。これからも支えたい。この投稿にフィードバックを返信してほしい。全部読む」という内容です。

マスクもパーマーさんも、修正の中身、いつ反映されるか、週間の使用上限や料金が変わるかどうかは書いていません。公式の changelog は、いまも10月27日付の v0.78.1 が最新です。

使用量が早く尽きる件では、マスクが11月初めに「Grok Bot の提供コストは収益に対して持続できないほど高かった」と答えていました。今回の投稿は、その続きとして改善を進めている、という表明です。
