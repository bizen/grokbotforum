Grok Bot チームの Lauren Tan さん（@poteto）が、サンフランシスコで11月10日から12日まで開かれる AI Engineer Code Summit で話すと X で告知しました。Grok Bot チームが先月、コードの質を落とさずに1万1,000件のプルリクエストを出した方法について話す予定だそうです。

公式のスケジュールによると、セッション名は「All Code Is Slop (Except Mine)」。現地時間11月11日（水）10時10分から10時30分まで、メインステージの Continental 4–6 で行われます。日本時間では11月12日（木）の3時10分からです。肩書きは SpaceXSI（xAI）の Principal Engineer となっています。

AI Engineer Code Summit は応募制のカンファレンスです。主催の @aiDotEngineer は10月の最初の登壇者発表で、Steve Yegge さんや Ramp の Zach Bruggeman さんと並べて Lauren さんの名前を挙げていました。同じ日のメインステージには Anthropic や Cloudflare の登壇者も並んでいます。

配信や録画が公開されるかは、告知の中では触れられていません。
