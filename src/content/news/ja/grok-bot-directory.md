SpaceXSI の Eric Zakariasson さん（@ericzakariasson）が11月18日（米国時間）、「grok-bot.directory を公開した」と X に投稿しました。Grok Bot のコミュニティ向けのディレクトリで、ほかの人が作った Bot やアプリを探して自分の Grok Bot に追加したり、自分の Bot を載せたりできます。Lauren Tan さん（@poteto）もこの投稿をリポストしています。

## Marketplace とのちがい

サイトの About ページによると、x.ai の Marketplace は公式が選んで載せるカタログです。Directory のほうは誰でも投稿できます。共有した Bot を投稿すると審査があって、通れば一覧に載ります。Marketplace の Bot もこちらに表示されます。Zakariasson さんも X の返信で同じ説明をしていました。

載せ方は、自分の Bot に「Share yourself as a public template」と頼み、出てきたリンクを Submit a bot のページに貼るだけです。たいていは数分で載り、人が確認するものは少し待つそうです。

載せてもらえない Bot の条件も書かれています。すでに載っている Bot のコピー、実在の人や他社製品の名前を自分のものとして使う Bot、本人に知らせずに人を追跡する Bot、中身や作者を偽る Bot、AI の安全ルールをすり抜けるための Bot、スパムやアダルト、人に害を与えるための Bot です。

並び順は3つあります。Trending は直近30日の追加数、Most added は掲載からの追加数の合計、New は新しい順です。数えるのは、このサイトで Add to Grok Bot が押された回数だけです。

## 追加する前に読んでおくこと

About ページには、コミュニティの Bot やアプリは作った人のもので、Grok Bot チームが作ったものではないとあります。Bot の審査は名前と説明だけを見て行うので、追加する前に説明を読んでほしいとのことです。アプリは掲載前に自動のセキュリティスキャンを受けます。ただ、公開元のサーバーで動くアプリは、つないだあとにそのサーバーがデータをどう扱うかまでは確認できません。信頼できる公開元のものだけ入れるよう書かれています。

11月22日にトップページを見たときは、Kyle Kane さんの「Live Bot Map」、Digg の「Digg - the latest everything」、Nima Owji さんの「Animator」などが最初のほうに並んでいました。Lauren さんの「dr eggbot v2」も載っています。このサイトにも [dr eggbot v2 の紹介ページ](/bots/dr-eggbot-v2/) があります。
