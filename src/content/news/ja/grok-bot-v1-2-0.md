Grok Bot の公式 changelog が11月12日、13日、16日に更新され、最新は11月16日付の v1.2.0 になりました。このサイトで前に取り上げた v1.0.1（11月11日）からの主な変更をまとめます。

## 11月12日（1.0.2 を含む）

- 画像で Markup を選ぶと、画像に直接描いたり番号付きのコメントを置いたりして、Bot に直してほしい箇所を伝えられます（0.79.2 以降）。
- 設定の Change profile photo でプロフィール写真を変えられるようになりました。
- 連携しているストアに保存したカードで払えないとき、Bot が Vault のカードか新しいカードを追加して支払えます。
- Bot が複数の人に一度にメールを送るときは、一人ずつ別のメールになり、ワンクリックの配信停止リンクが付きます。

## 11月13日

- Gift Concierge テンプレートが追加されました。予算付きのギフトリストを管理し、案を探し、配送を追い、承認したギフトだけを買います。
- Bot が X Chat のメッセージや X の投稿を書くと、Send、Discard、Post、Reply の付いた下書きカードになり、確認してから送られます。
- 会議で Disable Interactivity を選ぶと、Bot は話さず投稿もせずに会議に残ります。Turn Off Camera でカメラも消せます。
- 大人数の会議や外部の人がいる会議では、Bot は聞くだけで参加し、信頼できる会議かを確認してから加わります。
- 通話での声、話す速さ、言語を Bot に頼んで変えられます。
- iPhone のリマインダーで、特定の場所に着いたときや離れたときに知らせるものを Bot が作れます。
- Google Drive を連携すると、Docs、Sheets、Slides の編集ツールがすべて使えます。
- アカウントメニューの Invite teammates から、個人プランをチームにして招待を送れます。
- 設定に Send with ⌘↵ が追加され、Enter で改行、⌘ か Ctrl と Enter で送信にできます。

## 11月16日（v1.2.0）

- フライトの検索結果が作り直されました。便を選ぶと Full details と Book が出て、展開すると手荷物、変更、払い戻しの条件が見られます。
- 航空会社や出発時刻、乗り継ぎの条件に合う便がないときは、近い候補を出して、どの条件をゆるめたかを伝えます。
- ホテルの写真が大きなビューアーで開き、地図に拡大・縮小ボタンが付きました。
- チーム管理者は、チームの Bot の Proactive messages をダッシュボードでオフにできます（Teams 向け）。
- 修正や追加の依頼、同じ作業の繰り返しは、新しく始めずに既存のタスクの続きとして扱われます。
- 通話カードの Take over と End call は、押すと確認が出るようになり、誤操作で通話が切れなくなりました。
- コマンドの承認カードに実行するコマンドが全文表示され、隠し文字には印が付きます。Allow once は1回だけ実行します。

このほかにも細かい改善と修正がたくさん入っています。全文は changelog で確認できます。
