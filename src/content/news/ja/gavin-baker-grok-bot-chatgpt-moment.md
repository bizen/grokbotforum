ベンチャーキャピタルの a16z が日本時間11月28日0時4分、投資家の Gavin Baker さん（@GavinSBaker）が Grok Bot について話す約1分40秒の動画を X に投稿しました。投稿の見出しは「Gavin Baker says Grok Bot feels like another ChatGPT moment」です。

## 話していること

投稿に引用されている発言を訳すと、こうなります。

- 「Claude Code を手に入れて、いろいろ作った。でも Grok Bot で3分ほど Bot を作ったら、作ったものすべてについて、ずっと良いものができた」
- 「ポッドキャストの要約係が気に入っている。Grok Bot だと10秒でできる」
- 「Substack の要約、X の要約、話題や銘柄ごとの X のセンチメント追跡。Claude Code だとどれも何時間もかかったはずのものが、Grok Bot ではそれぞれ7〜12秒でできた。しかも出来がいい」
- 「自分にとって、Grok Bot はもう一度の ChatGPT モーメントに感じる」

冒頭では、23歳くらいの若い人たちが AI を母語のように使いこなしていて、自分はどれだけ頑張ってもああはなれないかもしれない、とも話しています。

## イーロンと Lauren さんが反応

日本時間11月28日2時21分、イーロン・マスクがこの投稿を引用して「Grok @Bot keeps getting better」（Grok Bot はどんどん良くなっている）と書きました。3時18分には、Grok Bot を作っている Lauren Tan さん（@poteto）も「give grok bot a try!」と添えて引用しています。

ポッドキャストや Substack の要約、X のセンチメント追跡は、どれもルーティンで毎日回す使い方と相性がいいものです。同じことを試したいなら、まず要約したい番組やアカウントを1つに絞って Bot に頼んでみるのが早いと思います。
