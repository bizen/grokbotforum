- Slack：メンション、特定のフレーズ、リアクション、任意のメッセージ
- GitHub / Linear / Sentry / PagerDuty のイベント
- Bot 専用アドレスへのメール（[Bot 用メールアドレス](/glossary/agent-email/)）
- [Webhook](/glossary/webhook/)

トリガーを作る前の出来事では起動しません。条件は狭く保ちます。広すぎると使用量を無駄にします。
