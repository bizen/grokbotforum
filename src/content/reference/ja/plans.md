結論から言うと、**X の Premium・Super・Ultra のどれかを契約していれば、追加料金なしで Grok Bot を使えます。** 新しく始める人は、X Subscription が入口です。

## 状況別：あなたはどれ？

| いまの状況 | どうすればいい？ |
|---|---|
| X Premium / Super / Ultra を契約している | そのまま使えます。[x.ai/bot](https://x.ai/bot) からアプリを入れてサインイン |
| X Plus、または無料 | Grok Bot は含まれません。Premium 以上にアップグレード |
| SuperGrok などを契約していて、Cursor の旧プランもある | SuperGrok を紐づけられます（下の「紐づけのルール」） |
| Cursor の Pro / Pro+ / Ultra（旧プラン）を契約している | そのまま使えます |
| 会社で使いたい | Cursor Teams なら全員利用可。Enterprise は管理者が有効化（[チームと企業](/docs/teams-and-enterprises/)） |
| とりあえず試したい | 対象アカウントなら **Start Trial** で 7 日間の使用量クレジット |

## X Subscription で使う場合

- **Premium・Super・Ultra** に含まれます（個人もチームのシートも）。**Plus と無料プランは対象外**です
- 使用量は Cursor・Grok アプリと**共通の週ごとの枠**から引かれます
- Super と Ultra は Premium より枠が大きくなります
- 枠を超えた分は前払いクレジットで支払います
- 使用量は grok.com/dashboard の **Usage** で確認できます
- 追加課金を止めたいときは、自動チャージをオフにするか、grok.com/dashboard/billing で月の上限を設定します

X の **X Chat** から Bot と話す機能も、同じく Premium 以上が必要です。

## Cursor の旧プランで使う場合

| プラン | 週の使用量 |
|---|---|
| Pro | 標準 |
| Pro+ | 多め |
| Ultra | 最大 |
| Teams（セルフサーブ） | シートごとの枠 |

週の上限を使い切ると、オンデマンド利用が有効なら Cursor 経由で追加課金されます。止めたいときは、アプリの **設定 → Usage & Billing** か cursor.com/dashboard で月の上限を設定するか、オンデマンドをオフにします。

## 紐づけのルール

Cursor の旧アカウントには、Grok 側の個人プランを紐づけて使用量を得られます。

| プラン | 紐づけ |
|---|---|
| SuperGrok / SuperGrok Plus / SuperGrok Heavy | 可 |
| X Premium+ | 可 |
| SuperGrok Lite / Grok Enterprise | 不可 |
| Grok Business のシート | 紐づけではなく **Sign in with Grok** でサインイン |

**注意したいこと**

- **紐づけは永久**で、自分では外せません。間違えたらサポートに連絡します
- **合算はされません。** Cursor のプランと紐づけたプランのうち、使用量が多いほうが使われます
- 対応関係は **Pro = SuperGrok = X Premium+**、**Pro+ = SuperGrok Plus**、**Ultra = SuperGrok Heavy**
- SuperGrok の残量（Grok アプリ）と Grok Bot の使用量は**別のメーター**です
- X Subscription の場合は紐づけるものがなく、プランの枠をそのまま使います

## スマホで契約する前に

- すでに上のどれかで使えるなら、**App Store や Google Play で二重に契約しない**でください
- アプリ内で買えるのは**月額の個人プランだけ**です。年額・チーム・企業向けは cursor.com から
- アプリ内で契約したものの解約・返金は Apple / Google 側で行います
- App Store の無料トライアルは、解約しないと有料になります（Grok Bot 自体の 7 日間トライアルとは別物です）

## よくある勘違い

- **「Grok アプリの SuperGrok 上限に達したら Grok Bot も使えない」** → 別のメーターです
- **「Grok Bot 専用の契約が必要」** → 不要です。上のプランに含まれます
- **「モデルを選べば安くなる」** → モデルは選べず、使用量は作業量で決まります

上限値は[上限値まとめ](/reference/limits/)に、料金・解約・返金の細かい話は [FAQ](/docs/faq/) にあります。
