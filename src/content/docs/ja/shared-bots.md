Bot には**個人**と**共有**の 2 種類があります。共有 Bot はドキュメントのように、チーム全体か指定した人・グループと共有します。

- 共有してもコピーは作られず、**全員が同じ Bot** を使います
- ただし**各自のチャットは非公開**で、持ち主やマネージャーにも見えません
- 共有 Bot は常にクラウドで動きます。手元の PC で動く Bot は共有できません

テンプレート（[Bot の使い方](/docs/bots/)）は各自に**コピー**を渡す仕組みなので、共有 Bot とは別物です。

## 使える人

Cursor のチームのメンバーで、Grok Bot を使える人です。サイドバーの **+** に **Browse shared Bots** が出ない場合は、チームに入っていないかアプリが古い可能性があります。

## チーム用の Bot を作って共有する

1. **+** → **Create a Bot** で作り、名前をつける
2. チームが何に使うのかを 1 文で説明する
3. アプリ・シークレット・スキル・ファイルを設定する（**共有相手の全員が使ってよいものだけ**）
4. Bot の名前をクリック → **Share**

**Who has access** で範囲を選びます。

- **Your team**：チーム全員
- **People you invite**：追加した人とグループだけ

追加する人の役割は 2 つです。

- **Collaborator**：チャットできる
- **Manager**：指示・スキル・記憶・アプリも変更できる

既存の Bot を共有することもできますが、その Bot のアプリやシークレットが全員のチャットで使えるようになるので、先に見直しましょう。

## 見つけ方

**+** → **Browse shared Bots** で一覧を開き、**Add** でサイドバーに追加します。仲間から送られたリンクを開いて **Start a chat** でも始められます。

## 誰のアプリと使用量が使われるか

- 既定では、**持ち主が追加したアプリとシークレット**を全員が使います
- 自分のチャットでは、あなたの個人アプリも**確認してから**使います。**Allow once**（今回だけ）／**Always allow**（今後も）／**Skip** から選択
- Slack のチャンネルやグループチャットでは、持ち主のアプリだけを使い、あなたのアカウントを使う前には確認します
- 接続したアカウントは、常にその時に答えている相手のために動き、他人のために使われることはありません
- 返信の**使用量は答えてもらった人**に計上されます

## どのコンピューターで動くか

| 場所 | コンピューター |
|---|---|
| 自分のチャット | 基本はあなたのコンピューター（あなたのファイルやログインが使える） |
| Slack の DM | あなたのコンピューター |
| Slack のチャンネル・スレッド、グループチャット | Bot 専用の共有コンピューター |

## 承認

危険な操作の前には、答えている相手に確認します。Slack のスレッドでは **Review an action** カードが出て、依頼した本人だけが **Allow once** / **Deny** を選べます。

## Slack に追加する

1. 持ち主かマネージャーが、Bot の詳細の **Bring to your team's Slack** で **Connect**
2. **Awaiting admin approval** と出たら、Slack の管理者が承認
3. **Connected** になれば、DM やチャンネルでのメンションで使えます

各メンバーは先に **設定 → General → Shared Bots** で **Link** を押し、Slack アカウントをつないでおく必要があります。スレッドで返信を続けている Bot は、メンションなしでも後続のメッセージに反応します。

## 編集・削除

- 持ち主とマネージャーが、名前やレンチアイコンから **Bot settings** を開いて編集できます
- **削除は持ち主だけ**。チーム全員のチャットとルーティンも含めて消え、元に戻せません
- 自分のサイドバーから外すだけなら **Hide from sidebar**（管理者が自動追加した Bot は外せません）

## その他

- スマホでも使えます。ただし共有 Bot は[メイン Bot](/docs/bots/)にはできません
- 仲間の共有 Bot とのボイスチャットはデスクトップのみ
- グループチャットに追加できますが、手元の PC で動く Bot とは一緒にできません

## 管理者の操作

Cursor ダッシュボードの Grok Bot セクションにある **Manage Shared Bots** で、Bot ごとのアクセス権と、メンバーのサイドバーへの**自動追加**（全員か特定のグループ）を設定します。詳しくは[チームと企業](/docs/teams-and-enterprises/)へ。

## 使えないときのメッセージ

| 表示 | 意味 |
|---|---|
| Bot Not Found | 削除されたか、共有されていない |
| No Access to This Bot | 制限されている。持ち主かマネージャーに依頼 |
| Your usage limit has been reached | あなたの使用量が尽きた |
| This Bot's owner has reached their usage limit | 持ち主の使用量が尽きた |
| Privacy mode conflict | あなたのプライバシー設定が持ち主より厳しく、あなたのコンピューターを使えない |
