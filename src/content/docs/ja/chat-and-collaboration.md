## Bot にメッセージを送る

サイドバーで Bot を開き、入力欄に書きます。テキスト・リンク・画像・ファイル、音声入力、ボイスチャットが使え、スキルを名前で呼んだり、`@` で Bot・グループ・ルーティン・アプリを指定したりできます。作業中に追加の指示を送ることもできます。

### 音声入力とボイスチャット

- **音声入力**：話した内容が入力欄に入り、確認してから送ります。デスクトップは `Cmd/Ctrl+D`
- **ボイスチャット**：1 つの Bot とのリアルタイムの通話。入力欄が空のときに **Start voice chat**（波形のボタン）を押します。声・速さ・言語を変更でき、言語は自動判定も可能。グループチャットでは使えません
- 通話後は通話時間と文字起こしのカードが残ります
- Bot から**ボイスメモ**が届くこともあり、文字起こしも読めます

### 送信前の下書き確認

Bot が書いたメールや Slack のメッセージは、まず**編集できる下書き**になります。宛先と本文を確認して **Send** か **Discard** を選びます。

- 特定の Bot だけ下書きをやめて直接送らせる設定もあります（Auto Review の設定には従う）
- ルーティンなど、あなたがチャットで頼んでいない Bot 自身のメールは、常に下書き止まりです

### 作業中に方向を変える

新しいメッセージはバックグラウンドの作業より優先されます。「今すぐ止めて」で即座に止まりますが、すでに済んだ操作は元に戻りません。

## X Chat で話す

X アプリ（iOS / Android）や x.com の X Chat からも、同じ Bot と話せます（順次提供、最新の X アプリが必要）。

- X Subscription の **Premium / Super / Ultra** が必要。**Plus には含まれません**
- Grok アカウントが Cursor アカウントに接続されている必要があります
- X Chat からの接続は個人アカウントのみ。会社管理のメールドメインやチームアカウントは Grok Bot アプリを使います
- 違う Bot が出る・「Something went wrong」と出る場合は、X アカウントが別の Grok アカウントにつながっている可能性があります。accounts.x.ai → x.com の順にサインインし直してつなぎ直します

## グループチャット

複数の Bot が 1 つの成果を目指し、引き継ぎを見える形で進めたいときに使います。

1. **New chat**（`Cmd/Ctrl+Shift+N`）を選ぶ
2. **To:** に **2〜6 個**の Bot を追加
3. 共通の目標と、次の段階の担当を書く

- 普通に書けば、関係のある Bot が自分で判断して答えます
- 担当がはっきりしているときは `@` でその Bot を指名
- `@everyone` は控えめに
- 承認依頼、ログインやシークレットの依頼、メール・Slack の下書きはグループには出ません
- 仲間の共有 Bot は追加できますが、手元の PC で動く Bot とは一緒にできません

### Bot 同士のやり取りを抑える

Bot は個別にあなたへ連絡したり、他の Bot に話しかけたりすることがあります。切り替えスイッチはないので、「私に聞かずに他の Bot に話しかけないで」と伝え、各 Bot に覚えてもらいます。**Bot の返信はすべて使用量に数えられる**ので、Bot の数を絞るほど節約になります。

## Bot 同士の引き継ぎ

Bot は他の Bot に非同期でメッセージを送り、仕事を渡せます。元データの担当と成果物の担当を分ける、下書きを専門の Bot にレビューさせる、といった使い方です。**段階ごとに担当は 1 つ**にすると重複が起きません。

Slack のチャンネルスレッドでは、個人の Bot は他の Bot に仕事を渡せません。Slack で引き継ぎたいときは[共有 Bot](/docs/shared-bots/)を使います。

## スレッドとリアクション

1 つの結果や承認への返事はスレッドで。リアクションは軽い確認用で、指示の変更や安全に関わる判断は文章で伝えます。

## よく使うショートカット（デスクトップ）

macOS は `Cmd`、Windows / Linux は `Ctrl`。

| 操作 | キー |
|---|---|
| 検索パレット | `Cmd/Ctrl+K` |
| Bot を検索 | `Cmd/Ctrl+Shift+F` |
| サイドバーの 1〜9 番目の Bot | `Cmd/Ctrl+1`〜`9` |
| 新しい Bot | `Cmd/Ctrl+N` |
| 新しいグループチャット | `Cmd/Ctrl+Shift+N` |
| 入力欄へ移動 | `Cmd/Ctrl+I` |
| 送信 / 改行 | `Enter` / `Shift+Enter` |
| 音声入力 | `Cmd/Ctrl+D` |
| チャット内検索 | `Cmd/Ctrl+F` |
| 設定 | `Cmd/Ctrl+,` |
| ショートカット一覧 | `Cmd/Ctrl+/` |

ボイスチャットにはショートカットがなく、ボタンから始めます。

## うまく頼むコツ

- 手順ではなく**欲しい結果**から書く
- 正しい情報源のリンクを渡す
- 変えてよいものと、承認が必要なものを書く
- リンク・スクリーンショット・作業ログなどの**証拠**を求める
- 仕事が変わったら、新しいスレッドか新しい Bot にする

依頼文の型は[依頼文の基本テンプレート](/prompts/request-template/)にあります。
