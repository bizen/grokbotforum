X の投稿やリプライで **@bot** をタグ付けすると、あなたのメインの Bot がそのタスクを受け取ります。作業と結果は Grok Bot アプリ内の会話に残り、X 上には受け付けの確認だけが投稿されます。

## 設定

1. grok.com の **Settings → Account** で X アカウントを接続する
2. 同じ Grok アカウントで Grok Bot を使えるようにする（[x.ai/bot](https://x.ai/bot) からアプリを入れるか、SuperGrok を紐づける）
3. 自分の Bot を 1 つ以上作る（共有された Bot はタグ付けの依頼を受けられません）

初回は、タグ付けの依頼が自動で作業を始め、Grok Bot の使用量を消費することが X から通知されます。

## Bot が受け取るもの

- タグ付けした投稿
- リプライ先の投稿
- 引用した投稿（静止画を含む）

## @bot の返信の意味

| 返信 | 意味 |
|---|---|
| 確認の 1 行 | Bot がタスクを受け取った |
| サインアップのリンク | 投稿した X アカウントに Grok アカウントが接続されていない |
| 「Grok Bot isn't set up yet」 | 接続はできているが、Bot がまだない |

## 利用できる地域

オーストラリア、英国、EU などの一部の地域では、まだ使えません。判定は X に登録されている国で行われ、現在地や VPN は影響しません。

## 返信がないとき

返信がなければ、Bot は依頼を受け取っていません。よくある原因：

- アカウントの地域がタグ付けに対応していない
- すでに @bot がいるスレッドで、自分では @bot をタグ付けせずに返信した
- 同じ投稿で @grok もタグ付けしている
- 投稿・リプライ先・引用のどれかに動画や GIF が含まれている
- 投稿がモデレーションを通らなかった
- Grok Bot が Grok アカウントに紐づいていない、または週の使用量を使い切った

## もっと X を使わせる

オプションの **X for Grok Bot** プラグインを入れると、Bot が投稿の検索、タイムラインの閲覧、メンションの確認、トレンドやブックマークの利用をできるようになります。プラグインがなくても @bot での依頼は届きます。
